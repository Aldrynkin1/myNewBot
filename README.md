# myNewBot

Привет! Это мой асинхронный Telegram-бот на Python, который ищет случайных собеседников, прокидывает сообщения и ещё имеет немного развлечений.

## Что здесь уже работает

- `/search` — найти собеседника
- `/next` — переключиться на нового партнёра
- `/stop` — закончить текущий диалог
- `/icebreaker` — случайный вопрос для поддержания разговора
- `/report` — пожаловаться на собеседника в случае некорректного общения
- `/count` — сыграть в математическую игру с собеседником
- `/fractal` — получить уникальный фрактал 
- автоматическая пересылка текста и медиа между собеседниками

## Админский набор

Для доступа к админским командам используется `ADMIN_USER_ID` + статус `is_admin` в базе.

Доступно:
- `/admin_stats` — общая статистика по боту
- `/ban <tg_id>` — забанить пользователя
- `/unban <tg_id>` — разбанить
- `/delete_user <tg_id>` — удалить все данные о пользователе из БД
- `/add_admin <tg_id>` — назначить нового администратора
- `/delete_admin <tg_id>` — убрать права администратора (только владелец)
- `/get_user_info <tg_id>` — информация о пользователе
- `/get_all_users` — список всех пользователей
- `/get_admins` — список администраторов
- `/get_banned` — список забаненных пользователей
- `/admin_help` — список админских команд

## Как запустить

В корне проекта запусти:

```bash
pip install -r requirements.txt
python3 -m app.main
```

## Переменные окружения

Создай файл `.env` с такими переменными:

```env
BOT_TOKEN=ТвойТокен
DATABASE_URL=postgresql+asyncpg://твой_ник_постгрес:твой_пароль_постгрес@localhost/имя_БД
ADMIN_USER_ID=твой_telegram_id (можно получить из бота @@GetMyIDo_Bot)
```

## Архитектура

- `app/main.py` — точка входа, инициализация бота, пуллинг и рассылка уведомлений
- `app/core/config.py` — настройки через `pydantic-settings`
- `app/core/database.py` — асинхронная БД, авто-создание таблиц
- `app/handlers/` — маршруты и команды бота
- `app/services/` — логика поиска пары и работы чата
- `app/repositories/` — crud для пользователей, матчей, админки
- `app/models/` — таблицы SQLAlchemy
- `app/utils/icebreaker.py` — темы для общения (случайный вопрос)
- `app/utils/count/` — Cython-реализация математической игры
- `app/fractals/` — генератор фракталов на Cython и Python

## Что важно знать

- `/start` регистрирует пользователя и выводит правила.
- Если пользователь уже в активном матче, `/search` не создаёт новую пару.
- Жалобы увеличивают `report_count`; после 5 жалоб бот автоматически банит пользователя.
- Команда `/fractal` генерирует картинку фрактала и отправляет её пользователю.
- Все сообщения пересылаются с помощью `message.send_copy`.
