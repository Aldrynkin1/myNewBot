# myNewBot

Современный асинхронный Telegram-бот на Python.

## О проекте

Асинхронный Telegram-бот с архитектурой Clean Architecture (routers → services → repositories).

Основные технологии:
- Python 3.11+
- aiogram 3.28.2
- FastAPI (для возможного вебхука)
- SQLAlchemy 2.0 + Alembic
- PostgreSQL
## Функциональность
[
### Для пользователей
- `/start` — Регистрация в базе данных и запуск бота.
- `/search` — Поиск случайного собеседника для общения.
- `/next` — Быстрое переключение на другого собеседника.
- `/stop` — Остановка текущего диалога.
- `/icebreaker` — Получение случайной темы или вопроса, чтобы начать беседу.
- `/report` — Жалоба на текущего собеседника за нарушения.
- `/help` — Вывод справки со всеми доступными командами.
- `Пересылка сообщений` — Автоматический безопасный обмен текстом и медиа внутри чата.

### Для администраторов
- `/admin_stats` — Просмотр общей статистики (пользователи, баны, матчи).
- `/ban <tg_id>` — Блокировка нарушителя по его Telegram ID.
- `/unban <tg_id>` — Разблокировка пользователя.
- `/delete_user <tg_id>` — Полное удаление профиля из базы данных.
- `/admin_help` — Список всех команд управления для админа.
]
